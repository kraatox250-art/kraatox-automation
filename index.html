KRAATOX Automation

KRAATOX Automation est un service web permettant de connecter un compte TikTok autorisé afin de gérer et publier automatiquement des contenus vidéo liés au projet musical KRAATOX.

Le service utilise TikTok Login Kit pour l'authentification et TikTok Content Posting API pour l'envoi et la publication de vidéos sur les comptes autorisés.
